# Magic Studio Plugin Ecosystem

This directory contains the foundation for Magic Studio's extensibility.

## Structure

- `api/`: Backend plugins (Python-based).
- `web/`: Frontend components and UI extensions (Next.js/React-based).

## Vision

Magic Studio aims to provide a modular environment where developers can contribute custom nodes, model implementations, and UI widgets without modifying the core codebase.

### Plugin Types

1.  **Nodes**: Custom workflow processing blocks.
2.  **Models**: New LLM, embedding, or reranking providers.
3.  **UI Components**: Specialized dashboards, visualizers, or custom input fields.
4.  **Tools**: Third-party tool integrations (API-based).

## Documentation

For instructions on how to build and register plugins, refer to the upcoming Magic Studio Developer Guide.
