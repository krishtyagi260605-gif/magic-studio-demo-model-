# Contributing to Magic Studio

We're thrilled you're interested in helping make **Magic Studio** the definitive AI workflow platform. Founded and maintained by **Krish Tyagi**, Magic Studio is a project built for transparency, security, and developer freedom.

## How to Help

### **Reporting Bugs**
If you find a bug, please create a GitHub Issue with the following details:
-   **Description**: What happened?
-   **Reproduction**: Steps to trigger the bug.
-   **Screenshot**: (If applicable).

### **Feature Requests**
Have an idea for Magic Studio? We'd love to hear it! Open a Feature Request on GitHub.

### **Code Contributions**
1.  **Fork the repo**: `git clone https://github.com/krishtyagi/magic-studio.git`
2.  **Create a branch**: `git checkout -b feature/your-awesome-feature`
3.  **Make changes**: Follow our coding standards.
4.  **Test**: Ensure all tests pass (`pnpm test` and `pytest`).
5.  **Submit a Pull Request**: Provide a clear description of your work.

## Code of Conduct

Magic Studio is a place for collaboration and innovation. We expect all contributors to treat each other with respect and focus on the common goal of advancing AI technology for all.
